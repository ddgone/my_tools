# My Tools 使用演示

## 启动工具箱

```bash
./my_tools.exe
```

你会看到一个漂亮的交互式菜单界面：

```
============================================================
  🛠️  My Tools - 个人工具箱
============================================================

  1. 📝 文本处理                    文本转换、格式化等工具
  2. ℹ️  关于                       查看工具箱信息

============================================================
请选择 (输入数字，0退出): 
```

## 使用示例

输入 `1` 并回车，进入文本处理子菜单：

```

  3. 去除空格                        去除首尾空格

============================================================
请选择 (输入数字，0返回上级):
```

输入 `1` 选择大小写转换：

## 导航提示

- **数字选择**：输入对应的数字选择功能
- **0 退出**：在任何层级输入 0 可以退出或返回上级
- **回车继续**：执行完工具后按回车返回菜单
- **清屏显示**：每次显示菜单前会自动清屏，保持界面整洁

## 添加新工具

### 方法 1：在现有分类下添加工具

编辑 `main.go` 中的 `createMainMenu()` 函数：

```go
menu.NewItem(
    "📝 文本处理",
    "文本转换、格式化等工具",
    []menu.MenuItem{
        // ... 现有工具
        
        // 添加新工具
        menu.NewToolItem(
            "统计字数",           // 标题
            "统计文本字数",       // 描述
            "word_count",        // 命令
            func() error {      // 执行函数
                return runWordCountTool()
            },
        ),
    },
),
```

然后实现工具函数：

```go
func runWordCountTool() error {
    scanner := bufio.NewScanner(os.Stdin)
    
    fmt.Print("\n请输入文本: ")
    if !scanner.Scan() {
        return fmt.Errorf("读取输入失败")
    }
    text := scanner.Text()
    
    count := len(strings.Fields(text))
    fmt.Printf("\n字数: %d\n", count)
    return nil
}
```

### 方法 2：创建新的分类

```go
Items: []menu.MenuItem{
    // ... 现有分类
    
    menu.NewItem(
        "🔧 系统工具",          // 新分类
        "系统相关工具",
        []menu.MenuItem{
            menu.NewToolItem(
                "查看系统信息",
                "显示系统详细信息",
                "system_info",
                func() error {
                    return runSystemInfoTool()
                },
            ),
        },
    ),
},
```

## 优势对比

### 之前的命令行方式
```bash
./my_tools text -upper -input file.txt
```
❌ 需要记住命令和参数
❌ 需要查阅帮助文档
❌ 不够直观

### 现在的 TUI 菜单方式
```bash
./my_tools
# 然后选择: 1 -> 1 -> 输入文本 -> 选择操作
```
✅ 可视化菜单，一目了然
✅ 无需记忆命令
✅ 交互式引导，不易出错
✅ 支持多级分类，便于组织

## 设计理念

1. **易用性优先**：用户不需要学习任何命令
2. **分层组织**：通过分类和子分类管理大量工具
3. **即时反馈**：每个操作都有清晰的提示和结果
4. **简单导航**：数字选择 + 回车，最简单的交互方式
5. **跨平台**：纯文本界面，任何终端都能完美显示
