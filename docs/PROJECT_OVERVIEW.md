# 项目总览

## 1. 产品定位

火蜥蜴工具箱当前不是一个“多页面桌面壳”，而是一个单页工作台：用户在同一窗口里浏览工具、配置参数、执行任务、查看日志、管理 SSH 连接，并逐步过渡到单工具导出。

## 2. 当前真实状态

- 已完成桌面宿主重构主线，Wails 后端与 Vue 前端已经形成稳定的工作台骨架。
- 已接通本地执行链路，旧 Go/Python 工具通过桥接继续复用。
- 已接通基础远程执行链路，但 SSH 安全、密钥认证和部分状态流还没有收尾。
- 已接通日志导出与单工具导出：Python 默认导出脚本源码，Go 支持源码/二进制两种导出模式，并支持工具级导出目标平台记忆。
- 文档已经按“当前有效 / 历史归档”重新整理，旧方案不再与现状混排。

## 3. 当前能力边界

### 已落地

- 单页工作台：活动栏、侧边栏、标签工作区、参数区、执行终端。
- 工具加载：内置 YAML manifest + 旧工具桥接并行工作。
- 执行路径：本地执行、基础远程执行、日志流回传、任务状态同步。
- 连接管理：SSH 连接的列表、表单、测试、编辑、删除。
- 导出能力：单工具另存为导出、最近导出目录、Go 导出模式、导出后自动打开目录、工具级导出目标平台记忆。
- 本地偏好：收藏夹、最近使用、参数历史、部分界面设置与设置页签记忆。

### 未闭环

- 任务中心与导出中心的完整业务页。
- 导出记录、批量导出与导出结果回看。
- SSH 链路的安全收口与密钥认证全链路一致性。
- 若干设置项与交互行为的收尾打磨。

## 4. 代码真相源

- 宿主入口：`app/main.go`
- 宿主 API 与 bootstrap：`app/app.go`
- 执行编排：`app/execution.go`
- SSH 存储：`app/internal/ssh/`
- 远程执行器：`app/internal/runtime/`
- 构建与单工具产物准备：`app/internal/builder/`
- 前端工作台：`app/frontend/src/components/`
- 工具规格与清单：`libs/core/toolspec/`、`libs/catalog/builtin/`

## 5. 当前主要问题

本轮已把可见问题统一收口到 [ISSUES_AND_REMEDIATION_PLAN.md](./ISSUES_AND_REMEDIATION_PLAN.md)，不再把问题列表散落在 README、计划稿和阶段总结里。

问题大类如下：

- 安全问题：归档解压路径穿越、SSH host key 校验缺失。
- 功能缺口：SSH keyPath 没有真正接入测试与远程执行。
- 状态流问题：新建 SSH 保存后的页签状态、远程任务取消清理、启动期错误兜底。
- 工程问题：Python 临时脚本并发冲突、窗口状态保存回退不足、构建脚本错误处理粗糙。
- 体验问题：导出中心缺位、部分设置项死角、帮助文案与实际快捷键不一致。
- 文档问题：旧版方案、旧路径、旧阶段结论混入当前文档。
