# 增强版 TUI 使用指南

## 🎯 新特性总览

### 1. ⏰ 最近使用记录
- 启动时自动显示"最近使用"分类
- 快速访问常用工具
- 显示上次使用的参数

### 2. 📝 参数记忆
- 自动保存每次使用的参数
- 运行工具时显示上次参数作为参考
- 方便快速重复执行相同操作

### 3. ⌨️ 键盘导航
- **↑/k** - 向上选择
- **↓/j** - 向下选择
- **→/l/Enter** - 展开目录或执行工具
- **←/h** - 收起目录或返回上级
- **q** - 退出程序

### 4. 🌳 树形展开
- 类似文件管理器的展开/收起效果
- 展开目录时保持其他目录可见
- 清晰的层级结构展示

### 5. 🎨 视觉区分
- 📁 折叠的目录（橙色）
- 📂 展开的目录（橙色）
- 🔧 工具（绿色）
- ⏰ 最近使用（粉色）
- 当前选中项高亮显示（紫色背景）

## 📖 使用教程

### 基础导航

1. **上下移动**
   - 按 `↑` 或 `k` 向上移动光标
   - 按 `↓` 或 `j` 向下移动光标

2. **展开目录**
   - 移动到目录上
   - 按 `→`、`l` 或 `Enter` 展开
   - 目录图标从 📁 变为 📂

3. **收起目录**
   - 在展开的目录上按 `←` 或 `h`
   - 或在任意位置按 `←` 收起所有目录

4. **执行工具**
   - 移动到工具上
   - 按 `Enter` 或 `→` 执行

### 实际示例

#### 示例 1: 使用大小写转换

```
1. 启动程序
2. 按 ↓ 移动到 "📝 文本处理"
3. 按 → 展开目录
4. 按 ↓ 移动到 "大小写转换"
5. 按 Enter 执行
6. 输入文本: hello world
7. 选择操作: 1 (大写)
8. 查看结果: HELLO WORLD
9. 按回车返回
```

#### 示例 2: 使用最近使用功能

第一次使用某个工具后：

```
1. 重新启动程序
2. 看到 "⏰ 最近使用" 分类
3. 按 → 展开
4. 看到之前用过的工具，显示上次参数
5. 直接选择执行，快速重复操作
```

### 键盘快捷键总结

| 按键 | 功能 |

| `↑` / `k` | 向上移动 |
| `↓` / `j` | 向下移动 |
| `→` / `l` / `Enter` | 展开目录 / 执行工具 |
| `←` / `h` | 收起目录 / 返回上级 |

## 💡 高级技巧

### 1. 快速访问常用工具

利用"最近使用"功能：
- 常用工具会自动出现在顶部
- 显示上次使用的参数，方便参考
- 无需层层导航，直达工具

### 2. 参数参考

执行工具时会显示：
```
🚀 启动工具: 大小写转换
============================================================

📝 上次使用的参数:
   operation: 大写
   text: hello world

请输入文本: 
```

这样可以：
- 快速回忆上次操作
- 参考之前的参数设置
- 减少重复输入

### 3. 树形浏览

展开多个目录同时查看：
```
🏠 主页
  📂 最近使用
    ⏰ 大小写转换
  📂 文本处理
    🔧 大小写转换
    🔧 文本反转
  🔧 关于
```

所有展开的目录都保持可见，方便对比和选择。

## 📊 数据存储

### 存储位置

Windows: `%USERPROFILE%\.my_tools\user_data.json`
Linux/Mac: `~/.my_tools/user_data.json`

### 存储内容

```json
{
  "recent_tools": [
    {
      "tool_name": "大小写转换",
      "tool_path": "text_case",
      "last_params": {
        "operation": "大写",
        "text": "hello"
      },
      "timestamp": 1234567890
    }
  ],
  "expanded_paths": ["text", "recent"]
}
```

### 数据管理

- 最多保留 10 个最近使用的工具
- 展开状态自动保存和恢复
- 下次启动时保持上次的浏览状态

## 🔧 添加工具

### 在树形结构中添加

编辑 `main.go` 的 `buildMenuTree()` 函数：

```go
{
    ID:          "new_tool",
    Title:       "🆕 新工具",
    Description: "工具描述",
    Type:        tui.TypeTool,
    Action:      runNewTool,  // 工具函数
},
```

### 添加新分类

```go
{
    ID:          "category",
    Title:       "📁 新分类",
    Description: "分类描述",
    Type:        tui.TypeDirectory,
    Children: []*tui.TreeNode{
        // 子工具...
    },
},
```

## ❓ 常见问题

### Q: 如何清除最近使用记录？

A: 删除用户数据文件：
```bash
# Windows
del %USERPROFILE%\.my_tools\user_data.json

# Linux/Mac
rm ~/.my_tools/user_data.json
```

### Q: 展开的目录太多了，怎么快速收起？

A: 按 `←` 键会收起所有展开的目录，回到初始状态。

### Q: 可以使用鼠标吗？

A: 当前版本仅支持键盘操作，这是为了保持简洁和高效。

### Q: 如何自定义颜色？

A: 修改 `internal/tui/tree_tui.go` 中的样式定义变量。

## 🎯 设计理念

1. **键盘优先** - 双手不离键盘，提高效率
2. **视觉清晰** - 通过颜色和图标快速识别类型
3. **记忆辅助** - 记住你的使用习惯，减少重复操作
4. **渐进展开** - 按需展开，避免信息过载
5. **即时反馈** - 每个操作都有明确的视觉反馈
