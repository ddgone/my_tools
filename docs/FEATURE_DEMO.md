# 增强版 TUI 功能演示

## 🎬 完整使用流程演示

### 1. 启动程序

```bash
./my_tools.exe
```

**界面显示：**
```
┌─────────────────────────────────────────────────────────┐
│  🛠️  My Tools - 个人工具箱                              │
└─────────────────────────────────────────────────────────┘

▶ 🏠 主页 - 工具箱主目录
    📁 ⏰ 最近使用 - 最近使用的工具 (0)
    📁 📝 文本处理 - 文本转换、格式化等工具
      🔧 大小写转换 - 转换文本为大写或小写
      🔧 文本反转 - 反转字符串内容
      🔧 去除空格 - 去除首尾空格
    🔧 ℹ️  关于 - 查看工具箱信息

↑/k 上  ↓/j 下  →/l/Enter 展开/执行  ←/h 收起  q 退出
```

**说明：**
- ▶ 表示当前选中的项目
- 📁 是折叠的目录
- 🔧 是工具
- 紫色背景高亮当前选中项

## ⌨️ 键盘操作总结

| 按键 | 效果 | 示例场景 |
|------|------|----------|
| `↑` / `k` | 向上移动光标 | 从"文本处理"移到"最近使用" |
| `↓` / `j` | 向下移动光标 | 从"最近使用"移到"文本处理" |
| `→` / `l` | 展开目录或执行工具 | 展开"文本处理"目录 |
| `Enter` | 展开目录或执行工具 | 执行"大小写转换"工具 |
| `←` / `h` | 收起目录 | 收起所有展开的目录 |
| `q` | 退出程序 | 关闭工具箱 |

## 🎨 视觉元素详解

### 图标系统

```
🏠 - 根目录/主页
📁 - 折叠的目录（橙色）
📂 - 展开的目录（橙色）
🔧 - 普通工具（绿色）
⏰ - 最近使用的工具（粉色）
▶ - 当前选中指示器（紫色）
```

### 颜色编码

- **紫色背景** (`#7D56F4`) - 当前选中的项目
- **橙色** (`#FFB86C`) - 目录名称
- **绿色** (`#50FA7B`) - 工具名称
- **粉色** (`#FF79C6`) - 最近使用的工具
- **灰色** (`#6272A4`) - 描述文字和帮助信息

### 布局结构

```
层级 1: 🏠 主页（根节点）
  层级 2: 📁 分类（一级目录）
    层级 3: 🔧 工具（叶子节点）
    层级 3: 📁 子分类（二级目录）
      层级 4: 🔧 工具
```

```json

  "recent_tools": [
    {

      "tool_path": "text_case",
      "last_params": {
        "operation": "大写"
      },
      "timestamp": 1234567890
    }
  ],
  "expanded_paths": ["text"]
}
```

### 第二次启动

```bash
./my_tools.exe
```

**效果：**
- "最近使用" 分类显示 1 个工具

- 显示上次使用的参数

## 🚀 高效使用技巧

### 技巧 1: 快速重复操作

1. 第一次使用工具时正常操作
2. 第二次使用时：
   - 展开 "最近使用"
   - 直接选择工具
   - 参考显示的参数
   - 快速完成相同操作

### 技巧 2: 批量浏览工具

1. 展开所有感兴趣的分类
2. 快速上下浏览所有工具
3. 找到需要的工具后执行
4. 按 `←` 收起所有目录

### 技巧 3: 参数参考

执行工具时显示的上次参数可以：
- 回忆之前的操作
- 复制相同的参数
- 基于上次结果调整
